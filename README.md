## 安装

### 懒人版

对你的 dsh 说：
```
安装一下这个皮肤包：https://github.com/Small-tailqwq/dsh-deep-whale
```

```sh
git clone https://github.com/Small-tailqwq/dsh-deep-whale
cd <harness>
dsh plugin --profile web add ../dsh-deep-whale/maid-atelier
```
