# ORCA LINK 状态角色源图

角色身份来自维护者提供的上善鲸鱼娘参考，署名及许可见包目录的 `NOTICE` 和
`LICENSE-ARTWORK`。动作通过内置 ImageGen 重绘；工具没有返回具体后端型号。
`prompts.json` 保存完整提示词及各输入的用途。源图不进入发行包。

`master.png` 保留角色身份与朝右、右手用鼠标的构图参考。`edit-reference.png`
是这次所有动作生成使用的同一输入。`neutral.png` 从本次待机图第 0 格提取，补齐为
444 × 444，作为所有状态共用的中性姿态和静态底层。

动作 PNG 均为 4 列 × 2 行的透明图，从左向右、从上向下读取。
`syncing.png` 由组装器从已配准的待机眨眼帧派生，其他八组保留独立源图。
图集按 standby、syncing、working、approval、input、review、complete、fault、offline、ready
排列，共 8 列 × 10 行，单格 256 × 256。ready 全行复用 neutral。

在 `orca-link` 安装开发依赖后，从仓库根运行：

```sh
node scripts/build-orca-status-atlas.mjs
cd orca-link
npm run build
```

组装器在源图两行之间的透明间隙切分，补齐统一画布，并用静止头发轮廓配准位置和比例。
`alignment.json` 保存配准结果。运行时只切换图格，不按人物重心平移或缩放。

- 待机、连接、审阅、离线只合成眼部，身体、头部轮廓与键鼠共用同一底层。
- 工作、授权、等待输入、完成和故障使用完整源帧；位置与比例统一配准。角色、手与设备
  保持同一张图中的连续轮廓，鼠标和键盘不以矩形区域跨帧替换。
- 连接的 0、1、2、6、7 格共用中性睁眼姿态；3、5 格共用待机第 1 格，4 格使用待机第 3 格。
  闭眼和睁眼沿同一路径往返，连接保持独立停留节奏。
- 完成保留轻微点头与微笑。完成、授权、等待输入和离线的第 7 格复用第 6 格，保持末态稳定。
- 等待输入的第 1–7 格在整帧配准后，仅对膝部、丝袜边缘及裙摆下部做连续局部形变，
  对齐共用中性坐姿；初始抬手帧保留前臂遮挡。校正参数写入 `alignment.json`，
  不跨帧粘贴腿部、手或设备，不影响其他状态及动作节奏。

所有行第 0 格相同，待机、连接、工作和审阅的第 7 格也回到这一中性姿态。
待机长时间睁眼、短暂眨眼；连接和审阅使用独立的停留节奏。
工作大部分时间双手打字，之后沿手腕过渡帧回鼠标。

故障按 0 → 1 → 2 → 3 → 4 → 5 播放，在第 5 格扶额姿态停留。
第 6、7 格专供回收：手降到胸前、鼠标上方，再回中性姿态；回收不重播惊讶表情。
其他事件动作结束后保持末格，切换时沿当前动作回到中性姿态，再进入最新目标状态。
状态提示立即更新，不等待角色收手。离线和就绪在末态停播，隐藏或减少动态效果时停止时钟。

替换源图后重新组装和构建，使资源哈希、运行时清单、`lib` 与 `skin.build.json` 同步。
